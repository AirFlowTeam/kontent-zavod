КАКИЕ НАСТРОЙКИ ПОЛУЧАЕМ ИЗ КАБИНЕТОВ
YouTube: личный API key каждого креатора, в его проекте включён YouTube Data API v3.
Instagram: Instagram App ID и App Secret, разрешения на профиль и статистику.
Threads: отдельные Threads App ID и App Secret, threads_basic и threads_manage_insights.
TikTok: Client key и Client secret, одобренные Login Kit и Display API.
VK: ID конфиденциального приложения и сервисный токен, отдельно согласованное video.
RuTube: для используемого публичного источника ключ не нужен.

Приложения настраиваются один раз на весь бот. Каждый креатор добавляет свои
ссылки. Для YouTube каждый креатор подключает личный API-ключ проекта Google Cloud
к выбранному каналу через форму в боте. Для площадок с личной
авторизацией владелец канала проходит официальный вход. Секреты приложений
сохраняются на сервере; собирать пароли креаторов не требуется.

ЧТО ЗАВИСИТ ОТ ПЛОЩАДОК
Для массового подключения нужны разрешения Meta/TikTok/VK. Регистрация приложения
не означает, что эти разрешения уже выданы. VK официально согласует video
в исключительных случаях через devsupport@corp.vk.com.
Используемый источник RuTube не возвращает лайки. Полнота VK Клипов также
не гарантирована. Ни серверный ключ, ни личный токен не снимают эти ограничения.
