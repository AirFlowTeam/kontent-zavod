# YouTube: исправление пустых каналов и личные ключи

Новый канал 202 был распознан YouTube API: `channels.list` вернул HTTP 200,
`videoCount=0`. Связанный uploads playlist вернул `404 playlistNotFound`.
Код ошибочно запрашивал его для пустого канала, трактовал ответ как проблему
доступа, затем скрывал исходную причину за анонимным парсером.

Исправлено:

- Подтверждённый API ноль публичных видео даёт 0 видео и 0 лайков без запроса
  несуществующего списка. Отсутствующий videoCount не превращается в ноль.
- В соответствии с новым требованием владельца YouTube собирается только с
  личным ключом, сохранённым у конкретного канала. Общий ключ и анонимные
  источники больше не используются для сбора YouTube.
- `/api`, карточки, маршрут и квитанция добавления ведут к личному ключу.
  Поле формы сразу открыто. Сохранение проверяет канал и чтение видео,
  шифрует ключ и ставит первую проверку в очередь.
- Старые кнопки проверки при отсутствии личного ключа предлагают подключение;
  ложного сообщения о запуске проверки нет. Исторические показатели сохранены.
- Ошибки в карточках показывают конкретное действие без сырых ответов и секретов.
  Приостановленный канал после подключения ключа просит возобновить сбор.
- В текстовых сообщениях ключи не импортируются: бот предлагает личную форму.
  Обновлены инструкции TXT, публичный гайд и памятки администратору.

Проверки исходников: 189 тестов, TypeScript и production-сборка прошли.
Сквозной тест формы проверяет сохранение шифротекста, выбор личного ключа,
полный сбор, запись метрик и истории. Отдельный тест исполняет реальную
функцию сборщика с заданным общим ключом и подтверждает отсутствие fallback.
Проверены ограничения владельца, повтор формы, ошибки ключа, лимиты и очереди.

[список роликов и ошибки каталога](https://developers.google.com/youtube/v3/docs/playlistItems/list).
