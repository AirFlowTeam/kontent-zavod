## Что работает в новой версии

- `/guide` и `/start` продолжают персональный маршрут по шести площадкам.
- Для каждой площадки нужно добавить все свои аккаунты или отметить её отсутствие.
- Ссылка, личный API-доступ и фактически полученные показатели проверяются отдельно.

- Ошибка ручного ввода доступа допускает исправление в той же ещё действующей форме.
- Неполные показатели и ограничения источников не превращаются в нули или полный успех.

## Что ещё нужно настроить

На момент деплоя на сервере отсутствуют приложения Instagram, Threads, TikTok и VK.
Официальный вход этих площадок пока недоступен. Креатор не может исправить это
одной ссылкой или сменой пароля. Администратор должен зарегистрировать приложения,
получить требуемые разрешения и ввести параметры через `configure-api.py`.
Точные кабинеты, scopes, callback URL и команды: `deploy/vps/API-ADMIN-GUIDE.md`.

YouTube: форма личного API key доступна, но ни общего серверного ключа, ни личных
подключений на момент проверки нет. Один общий ключ YouTube Data API v3 позволяет
собирать публичные YouTube-каналы без отдельных ключей каждого креатора.
RuTube использует публичный источник; лайки этим источником не предоставляются.

После настройки каждого приложения пройти реальный вход разрешённым аккаунтом,
проверить все нужные разрешения и дождаться результата сборщика. Проверки с
имитацией API не доказывают выдачу приложению разрешений соцсетью.
